Pipeline Genom Influenza A

COMP8035041 · Big Data Analytics
Magister Teknik Informatika · BINUS Graduate Program

Pipeline menyeluruh atas 1.586.912 sekuens genom Influenza A dari NCBI: dari pengambilan data, penyimpanan di HDFS, pemrosesan dengan MapReduce dan Spark di atas YARN, klasifikasi dengan Spark MLlib, sampai graph analytics di Neo4j.

Jelajahi

Atlas interaktif → Dashboard lima halaman: arsip, mutu dan ketepatan waktu, keragaman, graf kemiripan, dan reassortment. Lima diagram jaringan. Kode sumber → Delapan notebook pipeline, Docker Compose, konfigurasi Hadoop, dan skrip analisis lanjutan.

Menjalankan sendiri

Kredensial tidak ikut repositori. Siapkan dua berkas lebih dulu, lalu nyalakan klaster:

cp docker/.env.contoh docker/.env
cp docker/mysql-init.sql.contoh docker/mysql-init.sql
cd docker && docker compose --profile yarn up -d

Jalankan notebook 00_setup.ipynb sekali; ia membuat nb/bda_secret.json dari contoh dan memberi tahu bidang mana yang perlu diisi. Zona data tidak ikut repositori karena berukuran ratusan megabita dan dapat dibangun ulang dengan menjalankan notebook 01 sampai 06 berurutan.

Sumber data: NCBI Influenza Virus Database. Seluruh angka dihitung dari zona data lake proyek ini, bukan disalin dari literatur.

Graf kemiripan dan kandidat reassortment dibangun atas sampel maksimum 2.500 simpul per segmen. Pengukuran kinerja dilakukan pada satu mesin fisik, sehingga perbandingan relatif antar mesin pemrosesan sah tetapi angkanya tidak dapat digeneralisasi ke klaster produksi.
