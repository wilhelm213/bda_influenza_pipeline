Running it yourself

Credentials are not committed to the repository. Prepare two files first, then bring the cluster up:

cp docker/.env.contoh docker/.env
cp docker/mysql-init.sql.contoh docker/mysql-init.sql
cd docker && docker compose --profile yarn up -d

Run 00_setup.ipynb once; it creates nb/bda_secret.json from the template and reports which fields still need values. The data zones are not committed because they run to hundreds of megabytes, and they can be rebuilt by running notebooks 01 through 06 in order.

Data source: NCBI Influenza Virus Database. Every figure was computed from this project's data lake zones rather than copied from the literature.

The similarity graph and the reassortment candidates were built on a sample of at most 2,500 nodes per segment. Performance was measured on a single physical host, so relative comparisons between processing engines are valid but the absolute figures cannot be generalised to a production cluster.
